## Project Description
Gogo's Kitchen is a non-profit food relief scheme providing R150 food parcels and daily soup kitchen meals to vulnerable families in Kagiso. This website was developed to increase awareness, accept donations, and allow community members to request assistance.

This is NOT a restaurant - it is a community outreach NPO.

## Website Pages (5 pages)
1. **index.html** - Home - Mission, impact stats (5000+ families fed)
2. **about.html** - Our Story, NPO registration, team
3. **services.html** - R150 Food Parcel, Daily Soup Kitchen (11am-2pm), Family Support
4. **enquiry.html** - Volunteer & Donation Form with JavaScript Validation
5. **contact.html** - Contact details, Kagiso address, operating hours, embedded map

## Part 03 Improvements (SEO & Technical)
- Added `robots.txt` - Allows search engine crawling

- Responsive design - Mobile, Tablet, Desktop
- Accessibility - alt text, semantic HTML5, ARIA labels
